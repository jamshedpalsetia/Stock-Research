# Filing corpus

Plain-text conversions of official SEC EDGAR 10-K HTML filings:

- `AAPL_2025_10-K.txt` — Apple, fiscal year ended September 27, 2025
- `NVDA_2025_10-K.txt` — NVIDIA, fiscal year ended January 26, 2025
- `MSFT_2025_10-K.txt` — Microsoft, fiscal year ended June 30, 2025
- `GOOGL_2025_10-K.txt` — Alphabet, fiscal year ended December 31, 2025
- `AMZN_2025_10-K.txt` — Amazon, fiscal year ended December 31, 2025

Each text file starts with its SEC source URL. This is a static, manually
selected corpus; the application does not fetch or update filings.
